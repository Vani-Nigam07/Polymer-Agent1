# Finetuning encoder-decoder model for Polymer-Agent: 
- https://pubs.acs.org/doi/10.1021/acs.jcim.6c00343

## 1/3 of module for - https://github.com/BaratiLab/Polymer-Agent

this model architechture is adapted from https://github.com/john-bradshaw/molecule-chef and https://github.com/TheJacksonLab/OpenMacromolecularGenome
the model uses a graph network for encoding polymer strings.
and RNN as a decoder for the final product generation from a bag of reactants of polymers which have high SA scores.
